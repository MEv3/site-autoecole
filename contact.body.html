Contactez Permikar pour votre permis de conduire

Une question sur votre inscription, votre formation, votre planning ou le choix de votre forfait ? L'équipe Permikar est à votre disposition pour vous accompagner à chaque étape de votre parcours vers le permis de conduire.

Écrivez-nous

Décrivez votre demande avec le plus de précision possible : nous vous répondons dans les meilleurs délais.

Précisez par exemple votre expérience, le nombre d'heures déjà effectuées et votre objectif.

Vous pouvez aussi nous joindre directement au 01 42 68 50 28 ou sur WhatsApp.

Une question avant votre inscription ?

Vous ne savez pas quelle formule choisir ou combien d'heures de conduite pourraient être nécessaires ? Précisez-nous votre expérience, le nombre d'heures déjà effectuées et votre objectif. Une évaluation de départ avec Eval'Click Auto peut également vous aider à obtenir une première estimation.

Commander l'évaluation

Vous souhaitez obtenir votre permis rapidement ?

Permikar propose des formations adaptées aux candidats qui souhaitent concentrer leurs heures sur une période plus courte. Découvrez le fonctionnement de la formation intensive et l'organisation des heures de conduite.

Découvrir le permis accéléré

Vous devez encore préparer le Code ?

Participez au stage de Code accéléré en 5 jours ou entraînez-vous à distance avec Prépacode Tests Auto. Ces solutions vous permettent de préparer l'épreuve théorique avant de poursuivre votre formation pratique.

Voir les solutions de Code

Une question sur vos heures ou votre planning ?

Vous êtes déjà inscrit chez Permikar et souhaitez organiser vos cours ? Le guide de réservation détaille chaque étape de la plateforme. Vous pouvez également découvrir l'équipe pédagogique qui accompagne les candidats.

Lire le guide

Notre équipe peut notamment vous renseigner sur : les forfaits de conduite, les formations en boîte manuelle ou automatique, le permis accéléré, le Code de la route, l'évaluation de départ, le numéro NEPH, la réservation des heures, l'organisation de votre planning et les différentes étapes de votre inscription.
